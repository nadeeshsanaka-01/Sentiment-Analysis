# Sentiment-Analysis

The Sentiment Analysis System is a natural language processing (NLP) application designed to
analyze sentiment in textual data. It categorizes sentiments into three categories: positive,
negative, and neutral. The system is capable of visualizing the sentiment results based on
factors such as gender, age, language, and city. It integrates seamlessly with Google Sheets for
data collection via Google Forms and operates as a web application accessible over a LAN.
